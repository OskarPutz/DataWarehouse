# 1. One Big Table (FlatTable)

The FlatTable joins the fact table CAR_DAY with all its dimensions: CAR (with the LOCATION of the car),
EMPLOYEE (with the LOCATION of the employee), CLIENT, DATE, TIME and JUNK. Columns of the location of the car
are prefixed with *Car* (CarLocationName, CarCity, CarDistrict, CarStreet, CarLocationStatus) and columns of
the location of the employee with *Employee* (EmployeeLocationName, EmployeeCity). The FlatTable is extended
with:

- **MonthStartMileage (Numeric):** Mileage of the car on the first day of the month (Mileage of the tuple of
  the same car with Date = first day of the month).
- **ServiceMileage (Numeric):** Mileage if ServiceStarted = 1, otherwise 0.
- **LateRent (Numeric):** 1 if RentStarted = 1 and DelayDays > 0, otherwise 0.
- **UnexpectedService (Numeric):** 1 if ServiceStarted = 1 and ServiceKind = unexpected, otherwise 0.
- **new ClientSegment:** Driver segment based on AgeCategory: young driver (18-24), standard driver
  (25-34, 35-44, 45-54, 55-64), senior driver (65+), not rented.
- **new PeriodType:** Type of the day based on Holiday, BeforeHolidayDay, WorkingDay and Vacation (in this
  order): public holiday, before holiday, weekend, summer holiday, winter holiday, regular day.
- **new MonthStartMileageCategory:** Category of MonthStartMileage: up to 50 000 km, 50 000 to 100 000 km,
  100 000 to 200 000 km, over 200 000 km.
- **new SatisfactionLevel:** Client's satisfaction based on CarConditionRating of the rent issued on the day:
  satisfied (4-5), neutral (3), dissatisfied (1-2), no survey (SurveyAnswered = 0).

# 2. Dimensional Model

## Fact Definitions

**Fact 1 (Car day fact)**

- **Description:** State of one car of the fleet on a specified day: rented by a specified client in a
  specified age category, handled by a specified employee of a specified rental point, in the service of a
  specified type, or idle. The rent issued on this day (at a specified hour) and the service starting on this
  day are described by the same fact.
- **Fact table:** Car_day
- **Granularity:**
    - A specified day
    - A specified car assigned to a specified rental point within one price category
    - A specified employee working in a specified rental point (or "not rented")
    - A specified client in a specified age category (or "not rented")
    - A specified hour of rent issue (or "no rent")
    - A specified return status, rental length, service type, mileage category and car age category
- **Measures and aggregation functions:**
    - Number of car days: COUNT(1)
    - Number of cars: DistinctCount(LicencePlate)
    - Number of rented days: Sum(RentedDay)
    - Number of service days: Sum(ServiceDay)
    - Number of available days: Sum(AvailableDay)
    - Number of idle days: Sum(IdleDay)
    - Km driven: Sum(KmDriven)
    - Number of rentals: Sum(RentStarted)
    - Rental revenue: Sum(RentCost)
    - Rental days of issued rents: Sum(RentalDays)
    - Delay days: Sum(DelayDays)
    - Number of late rentals: Sum(LateRent)
    - Number of services: Sum(ServiceStarted)
    - Number of unexpected services: Sum(UnexpectedService)
    - Service cost: Sum(ServiceCost)
    - Mileage at service: Sum(ServiceMileage)
    - Km since last service: Sum(KmSinceLastService)
    - Number of surveys: Sum(SurveyAnswered)
    - Car condition rating: Sum(CarConditionRating)
    - Number of reported issues: Sum(IssuesReported)
    - Likelihood to rent again: Sum(LikelihoodToRentAgain)
    - **Utilization Rate** = Number of rented days / Number of available days
    - **Utilization Gap** (distance to the 80% target of the CEO) = Utilization Rate − 0.80
    - **Idle Rate** = Number of idle days / Number of available days
    - **Utilization Contribution** (share of the overall utilization of the fleet generated by an employee
      or a client, e.g. a client who rented cars for 10 days out of 1 000 available days of the fleet
      contributed 1%) = Number of rented days / Total number of available days of the fleet
    - **Average Rental Length** = Rental days of issued rents / Number of rentals
    - **Revenue per Available Day** = Rental revenue / Number of available days
    - **Late Return Ratio** = Number of late rentals / Number of rentals
    - **Km per Rental Day** = Km driven / Number of rented days
    - **Average Mileage at Service** = Mileage at service / Number of services
    - **Average Km since Last Service** = Km since last service / Number of services
    - **Unexpected Service Ratio** = Number of unexpected services / Number of services
    - **Service Cost per Car** = Service cost / Number of cars
    - **Average Car Condition Rating** = Car condition rating / Number of surveys
    - **Issue Ratio** = Number of reported issues / Number of surveys
    - **Average Likelihood to Rent Again** = Likelihood to rent again / Number of surveys

# 3. Checking the Feasibility of Queries Based on the Multidimensional Model

|---|---|---|---|
| 1.1 | Compare the idle time of rentals of different fuel types in the analyzed month relative to previous months. | Number of idle days, Idle Rate | Fuel Type, Date Month |
| 1.2 | What car brands and models have the lowest idle time in the current and the previous month? | Number of idle days | Car Hierarchy, Date Month |
| 1.3 | Compare individual employees in terms of the utilization rate of rentals handled in the current and the previous month. | Utilization Contribution | Employee Hierarchy, Rental Point Name, Date Month |
| 1.4 | What age group is responsible for the majority of utilization rate? | Utilization Contribution | Client Age Category |
| 1.7 | Which gender tends to choose which fuel type? | Number of rentals | Client Gender, Fuel Type |
| 2.1 | What is the utilization rate of the cars in relation to the mileage at the beginning of the month? | Utilization Rate | Month Start Mileage Category, Date Month |
| 2.2 | What is the average mileage at service for individual fuel types, brands and car age categories? | Average Mileage at Service | Fuel Type, Car Brand, Car Age Category |
| 2.3 | Which gender drives more km per rental day? | Km per Rental Day | Client Gender |
| 2.4 | What is the car’s idle time in relation to cost of servicing? | Number of idle days, Service cost | Licence Plate, Date Month |
| 2.5 | What is the utilization rate of cars exceeding a certain mileage/age, by client age group? | Utilization Contribution | Mileage Category, Car Age Category, Client Age Category |
